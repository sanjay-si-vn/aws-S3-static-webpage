# AWS S3 Static Website Hosting

## Project Overview
This project demonstrates hosting a modern static website using Amazon S3 Static Website Hosting.

## Technologies Used
- AWS S3
- HTML
- CSS
- Static Website Hosting

## Features
- Responsive modern UI
- Serverless
- Glassmorphism design
- Hosted directly on AWS S3
- Public website endpoint

## Architecture
User → Amazon S3 → Static Website

## Learning Outcome
- S3 bucket configuration
- Static website hosting
- Bucket policy management
- Public object access
- Cloud-based frontend deployment
